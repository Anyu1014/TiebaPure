# 功能与双端差异

“实现”表示已有源码路径，不表示真实账号与所有设备均已验收。iOS 保留固定上游原功能；Android 为本次新增移植。

| 功能 | iOS | Android | 本次运行证据 |
| --- | --- | --- | --- |
| 首页、吧内最新/精华、排序、主题/回复搜索 | 保留 | 实现 | Android 首页→帖子→搜索→吧列表真实匿名接口通过 |
| 帖子分页、只看楼主/倒序、楼中楼 | 保留 | 实现 | Android 帖子实际显示；所有排序/楼中楼组合未逐项验收 |
| 图片预览/保存、视频、语音 | 保留 | 实现 | Android 媒体策略/存储测试；真实音视频播放和系统保存未验收 |
| 百度网页登录、加密会话、退出/换号 | 保留 | WebView + Keystore 实现 | Android 假会话加密、备份排除、退出测试通过；未真实登录 |
| 关注/粉丝、资料、收藏、消息、签到、点赞 | 保留 | 实现 | 协议与编译检查；未真实账号验收 |
| 我的点赞：云端主帖/回帖/楼中楼列表与定位 | 实现 | 实现 | 官方H5契约、共享合成分页回归与编译通过；未真实账号/设备验收 |
| 消息内私信、主页发私信/复制ID | 原生会话与手动发送 | 原生会话与手动发送 | iPhone真实账号只读历史查询、双端协议/模拟网络回归与编译；真实发送与已有会话完整性待验收，见[私信说明](PRIVATE_MESSAGES.md) |
| 自动回复、离线补扫确认、历史任务与原帖定位 | 实现；后台受系统刷新调度限制 | 实现；可选常驻通知保活 | 模拟后端核心回归、编译检查；未真实自动发评和长时间后台验收，见[自动化说明](AUTOMATION.md) |
| 发主题/回复与图片≤9张、楼中楼、表情与草稿 | 保留 | 实现 | 严格提交策略 5 项 fixture 测试通过；未真实发送 |
| 本人主题删除、昵称/简介/性别修改 | 保留 | 实现；删帖确认与本人检查 | 未真实账号写入 |
| 屏蔽、历史/阅读位置、搜索/筛选/批量管理 | 保留 | 实现 | Android 500 条限额、导入安全测试通过 |
| 整帖正文/楼中楼、图片/完整媒体分级离线 | 保留 | 实现 | Android 正文保存及断网重开通过；大快照校验测试通过 |
| 备份导入/导出 | 原 `.tiebapurebackup` | 独立 JSON 格式 | **两端备份不互通**；Android 不包含账号、草稿、字体与媒体 |
| 系统/浅/深主题、字号、本机字体 | 保留 | 实现 | 编译检查，字体/主题所有组合未验收 |
| 底栏收缩、快速回看展开、头像/位置、文字开关 | 实现；TabView导航+玻璃浮层 | 实现；复用磨砂浮层 | 统一手势入口，短/长页/表单/静态页UIKit宿主及速度/方向回归通过；设备触感未验收，见[底栏说明](BOTTOM_BAR.md) |
| 平板双栏 | iPad 原布局 | 阅读宽度≥840dp 时列表+详情 | 未做真实平板设备验收 |
| 分享和外部链接 | Safari Action 扩展+Scheme | Android 分享文本接收+Scheme | Swift 路由断言与 Android 深链接启动通过 |

当前 Scheme `tiebapure://thread/<id>`、`tiebapure://forum/<name>`；iOS 解析器同时保留旧 `tiebapure://` 输入兼容，但系统注册使用新 Scheme。HTTPS 外部入口限定真实 `tieba.baidu.com` 主机。

Android 限额：历史/阅读位置各500条，本地保存100帖；单离线正文快照8MiB，总正文128MiB，总媒体512MiB；备份文件最多8MiB。正文抓取另限制2Mi字符、3万条记录和分页推进，超限保留已有版本。媒体按单文件限额下载，拒绝不可信地址、异常图片元数据和未知导出格式。

Android 图片预览支持捏合缩放，尚未实现平移；没有移植 iOS 全部专用动画、手势和细节布局。手动媒体模式隐藏列表预览图，正文图片需点击加载；头像/表情仍用于基本识别。两端没有共用用户数据目录，也没有新增跨端账号/数据同步后端。

2.1增加私信图片、录音/语音播放、表情及已读事件展示；Android返回吧内缓存列表/分页/滚动位置，并显示楼层、按数字楼层正倒序、恢复用户主题点赞数。iOS草稿失败重试重建后端，仍不可用时保留旧稿继续编辑。当前为源码验证，设备及真实附件发送范围见[2.1记录](releases/2.1.md)。

“我的→浏览→我的点赞”使用贴吧账号的userAgree云端列表，支持全部/主帖/回帖和完整服务端分页，不受本地历史500条限制。按官方页面说明，当前云端范围为2023年1月1日至今；以TID+PID保留同主题多条回复并定位楼层/楼中楼。更早数据未取得可验证接口，真实账号与设备定位尚待验收。本功能已纳入2.2/build78签名包，真实账号与设备验收仍未完成。
