# TiebaPure 2.5

## 主要变化

### 私信

- 进入会话即定位到底部：打开聊天不再先渲染顶部再滑下来，首帧就是最新消息。
- 修复连续发送失败：官方提交接口在连发时只回“成功”信封、不带回执 id，旧逻辑把这种情况判成失败；现在按信封 `code=0` 视为已提交，缺回执时用本地记录号补齐。
- 发送失败会直接给出原因（服务端返回码/文案、回执不一致的具体字段），不再只有一句笼统的错误。
- 会话记录阅读位置：下次进入按上次读到的地方定位，未读边界更准。
- 发送能力只保留文本：图片与语音发送已在 2.4 从双端移除，接收侧的图片预览与语音就地播放保留。

### 首页与浏览

- 首页改为个性化推荐接口，列表内容与官方客户端更接近。
- 首页卡片展示热门评论，点击热评直接跳到帖子内该楼层。
- 首页工具栏新增未读消息入口（带红点）与「回到顶部」热区。
- 新增「图片原比例显示」开关：单图按真实宽高比展示，不再被裁成正方形。

### 其它

- 节点/接口结构、协议定义与抓包样本同步更新。
- 版本号：2.5（Android versionCode 92，iOS build 92）。

## 验证

- Android：`testDebugUnitTest` 125 项通过 / 6 跳过；`assembleRelease` 通过并在 API 35 模拟器上完成发送、连发、进入贴底实测。
- iOS：`xcodebuild -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build` 通过，签名归档与导出通过；本机无 iOS 运行时，未做真机验证。
