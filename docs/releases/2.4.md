# TiebaPure 2.4

2026-11-16，双端 build89。

## 变化

- 设置新增“回复栏收缩后位置”，居左、居中、居右三种，与悬浮导航底栏分开保存；首次升级沿用原底栏位置并立即写入独立偏好。Android 回复条复用 62dp 高度与系统栏/键盘加 8dp 的底边距，iOS 保持 62pt 并优先参考上一次可见的原生底栏锚点，键盘或位置失效时回退 8pt。
- Android 私信移除图片与语音发送：会话输入区只保留文本、表情与发送，上传接口、录音器、图片预处理、`RECORD_AUDIO` 权限及对应单测一并删除；接收侧图片预览、语音播放与历史媒体气泡保留。iOS 仍保留原有媒体发送流程。
- Android 私信输入区改为单行：输入框、表情按钮（48dp）与发送按钮（横向内边距 8dp）同排居中对齐。
- Android 私信图片消息不再套用气泡底色，改为透明 Surface 并去掉 6dp 内边距，图片以圆角直接呈现。

## 验证

- Android：115 项单元测试通过（6 项条件跳过），`assembleRelease` 与签名校验通过；会话输入区在 AVD `dev`（emulator-5580，android-35 模拟器）注入模板账号后渲染确认，Debug 包启动正常。
- Android 仪器测试：`PrivateMessagesInstrumentedTest` 中既有的 IME 内缩断言在 API 35 模拟器上与 2.3 的 HEAD 构建表现一致（未复现位移），其余断言通过；`InlineReplyInstrumentedTest` 调用 `FloatingReplyReader` 的过期参数已修正。
- iOS：源码未随本次私信改动，重新生成工程并按 Release 归档出未签名 IPA，未做真机安装验收。
