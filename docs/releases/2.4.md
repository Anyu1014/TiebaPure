# TiebaPure 2.4

2026-11-16，双端 build 89。

## 变化

- 双端私信只发送文本：会话输入区保留文本、表情与发送键，图片与语音发送的上传接口、录音器、图片预处理、对应单测以及麦克风权限说明一并删除；接收侧的图片预览与语音播放照常可用。
- 私信输入区改为单行：输入框、表情按钮与发送键同排居中对齐；Android 端图片消息不再套气泡底色，图片以圆角直接呈现。
- 双端私信气泡与输入区按 iOS 端设计统一：半透明气泡底、14pt 圆角、语音条 44pt 高与 8pt 圆角、无边框填充输入框；图片与语音消息不再套气泡底色。Android 端语音改为就地播放，不再弹窗。
- 设置新增“回复栏收缩后位置”，居左、居中、居右三种，与悬浮导航底栏分开保存；Android 回复条复用 62dp 高度与系统栏/键盘加 8dp 的底边距，iOS 保持 62pt 并优先参考上一次可见的原生底栏锚点。

## 验证

- Android：115 项单元测试通过（6 项条件跳过），`assembleRelease` 与签名校验通过；在 AVD `dev`（emulator-5580，android-35）安装签名包冷启动验证。
- Android 仪器测试：`PrivateMessagesInstrumentedTest` 中既有的 IME 内缩断言在 API 35 模拟器上与 2.3 的 HEAD 构建表现一致（未复现位移）；`InlineReplyInstrumentedTest` 调用 `FloatingReplyReader` 的过期参数已修正。
- iOS：`signed-archive` 与 `export` 均成功（Development 签名，team `UQ6YYY43ZY`）；本机无 iOS 模拟器 runtime，单测未执行。
