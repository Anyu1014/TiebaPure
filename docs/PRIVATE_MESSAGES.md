# 私信

双端消息包含“回复我的”“@我的”“私信”。私信列表与会话隐藏根悬浮底栏，返回后恢复。会话行显示头像、昵称、最新消息、时间，未读数显示在头像右上角；进入会话清除本机未读计数。未知或不支持的非文字消息使用具体类型提示，不伪装为已解析文字。2.1已支持图片、语音与表情；官方type22系统事件不作为用户气泡。

主页“发私信”、手输主页 ID，以及“从关注的人中选择”复用同一收件人校验。展示 ID 通过官方 getUserByTiebaUid/cmd309702 换取真实账号 UID，并核对回包展示 ID；不可直接把展示 ID 当成账号 UID。关注列表提供真实 UID、昵称与头像。选择用户仅打开会话，不自动发信。主页 ID 复制按钮只复制显示数字。

## 官方通道与加密

此前 pim.baidu.com REST 与 pimc.baidu.com:443 的 BIM 协议（method50/94/93/55）虽然给出消息回执和可查询记录，但用户确认官方客户端收不到，已移除。不能用这些回执作为官方互通证据。

当前本地源码采用官方 Tieba LCS 固定端点 `ws://im.tieba.baidu.com:8000/`，用户已明确批准仅对该固定端点使用官方应用层加密 WS。其余网络仍保留原 HTTPS 策略，没有全局允许明文 HTTP。帧头9字节，对应 command 与 sequence；正文为独立共享 proto2 投影，保留显式零值字段与未知字段。

登录采用匿名密钥引导、匿名加密回包校验、再加密提交账号资料：随机32字节ASCII秘密由固定官方 RSA 公钥 PKCS1 包装；会话 AES256/ECB/PKCS7 密钥按官方 PBKDF2-HMAC-SHA1 参数派生。只有可解密的匿名成功回包之后才提交 BDUSS/STOKEN；登录资料从不放入未加密引导或 WS 握手。再核对登录返回账号 UID。没有明文登录回退，也没有自动重试发送。

command1001 登录，202003 同步，205001 手动发信。同步携带服务端组游标及新版私信 repair 字段；发送使用实际 Tieba UID、文字类型1、用户类型0、唯一 record ID，并核对回执的收件人、record ID 与有效消息 ID。未知结果保留输入并阻止重复点击，不把本地气泡视作实际送达。连接、响应、压缩数据与本地文件均有大小边界；取消时关闭连接，不记录凭据或服务器原始错误正文。

## 会话记录

官方同步消息按双方实际 UID 分开入库，拒绝资料身份冲突，去重后更新最新消息和本机未读数。历史数据与游标存放于应用私有目录，以账号 UID 分文件，消息不进入业务备份；iOS另使用文件保护并排除系统备份。先成功落盘再更新内存游标。旧 BIM 的测试气泡与空会话不会迁移为官方记录。服务端没有返回的历史不伪造为已同步；新通道启用前的全量历史恢复仍需单独核验。

## 相关功能

回复编辑器在图片/表情旁提供艾特，复用关注人选择，在光标处插入原始用户名。搜索支持昵称结果列表与主页数字 ID，点选打开用户主页。

## 2.1 媒体与已读事件

- type1保留文本与贴吧表情；type2使用官方数组`[{src,big_src,type:"3",bsize}]`；type3使用`[{type:"10",voice_md5,during_time}]`，私信时长单位为秒。
- 图片使用HTTPS uploadPicture分片和有效原图收据；语音使用HTTPS chunkupload/voice_fin_chunk_upload，30720字节分片、整文件MD5、签名及最终voice_md5收据。Android录AMR，iOS录8kHz/16bit/单声道PCM WAV，最长60秒。服务器拒绝时保留附件，不自动重发；发送未知继续阻止重复点击。
- type22、eventId22001的eventParam含groupId与readMsgId。原始事件保留在账号私有缓存中，展示时排除；只有对方发给当前账号且group匹配的watermark会把对应自己已发消息标为“已读”。本机未读计数不包含这些系统事件。没有推断缺失回执为“已读”，也没有增加未核验的出站已读请求。
- 录制、选图、上传、换号/换会话/离页沿用代次与取消保护，图片与录音单独发送，已有文字输入保留。媒体图片复用安全加载组件与原有预览，语音复用播放器。

官方静态参考已确认上述类型和上传结构；尚未取得截图中具体气泡的原始事件，不能断言截图的每条未知类型都为已读。新增媒体上传/发送仅经过模拟网络与协议回归，不等于官方客户端实际送达。详见[2.1验证](releases/2.1.md)。
